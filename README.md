# Mini Bank

**Mini Bank** — учебное консольное банковское приложение на Java 21 для работы с клиентами, счетами и денежными переводами. Проект демонстрирует два подхода к работе с PostgreSQL: **JDBC** и **Hibernate ORM**, без использования Spring Framework.

## Возможности

- Хранение клиентов, банковских счетов и истории переводов в PostgreSQL.
- Переводы между счетами с проверкой суммы, доступного баланса, валюты и статусов счетов.
- Транзакционное обновление балансов и сохранение записи о переводе.
- Работа с данными через две взаимозаменяемые реализации репозиториев: JDBC и Hibernate.
- Управление статусами счетов, включая закрытие и запрет повторного открытия закрытого счета.
- Отчеты по клиентам, счетам, балансам и переводам.
- Отдельная демонстрация возможностей Hibernate: lazy loading, proxy, кэш первого уровня, dirty checking и проблема N+1.

## Технологии

- **Java 21**
- **Maven**
- **PostgreSQL**
- **JDBC** (PostgreSQL JDBC Driver)
- **Hibernate ORM 6.6.4.Final** и **Jakarta Persistence API**
- **Lombok**, **SLF4J**

## Структура проекта

Основной код находится в `src/main/java/german/dev`:

- `domain` — сущности `Client`, `Account`, `Transfer` и перечисления.
- `dao/jdbc` — реализация доступа к данным через JDBC.
- `dao/hibernate` — реализация доступа к данным через Hibernate.
- `service` — бизнес-логика переводов и формирование отчетов.
- `config` — конфигурация подключения к БД и Hibernate.
- `validation` — проверки данных перед операциями сохранения и обновления.
- `demo` — демонстрация особенностей Hibernate.
- `src/main/resources/schema.sql` — SQL-скрипт создания структуры базы данных.
- `src/main/resources/data.sql` — SQL-скрипт наполнения базы тестовыми данными.
- `Main.java` — точка входа и выбор режима работы.

## Требования

Перед запуском необходимы:

1. JDK 21.
2. PostgreSQL с доступной локальной или удаленной базой данных.
3. IntelliJ IDEA или другая IDE с поддержкой Maven.

## Настройка базы данных

SQL-скрипты находятся в `src/main/resources`:

- `schema.sql` — структура базы данных (таблицы и ограничения);
- `data.sql` — тестовые данные.

Для запуска:

1. Установите PostgreSQL и создайте базу данных, например `mini_bank_test`.
2. Подключитесь к созданной базе через SQL-консоль IntelliJ IDEA или другой SQL-клиент.
3. Выполните сначала `src/main/resources/schema.sql`, затем `src/main/resources/data.sql`.
4. Настройте подключение приложения к этой базе через переменные окружения, указанные ниже.

Hibernate использует `hibernate.hbm2ddl.auto=validate`: он проверяет существующую схему, но не создает таблицы автоматически.

## Настройка подключения

Приложение получает параметры подключения из переменных окружения:

| Переменная | Пример значения |
| --- | --- |
| `DB_URL` | `jdbc:postgresql://localhost:5432/mini_bank_test` |
| `DB_USER` | `postgres` |
| `DB_PASSWORD` | Ваш локальный пароль PostgreSQL |

В IntelliJ IDEA откройте **Run → Edit Configurations**, выберите конфигурацию запуска класса `german.dev.Main` и добавьте переменные в поле **Environment variables**.

**Не сохраняйте реальные пароли в исходном коде или репозитории.**

## Сборка и запуск

Откройте проект как Maven-проект и выполните сборку:

```bash
mvn clean package
```

Запустите класс `german.dev.Main` через IntelliJ IDEA. Режим выбирается в поле **Program arguments**:

| Аргументы | Назначение |
| --- | --- |
| `jdbc` | Работа через JDBC |
| `hibernate` | Работа через Hibernate |
| `hibernate --orm-demo` | Демонстрация механизмов Hibernate |

Если аргументы не заданы, используется режим `hibernate`.

Обычный запуск выводит демонстрационные отчеты. Автоматический демонстрационный перевод в `Main.java` по умолчанию отключен (`executeTransfer = false`), чтобы запуск не изменял балансы счетов.

**Примечание:** некоторые демонстрационные отчеты используют заранее заданные идентификаторы клиентов и номера счетов. Для их корректного вывода нужны соответствующие тестовые данные; при собственной базе значения можно изменить в `Main.java`.

## Отчеты

Приложение формирует:

1. Сводку по клиентам: количество счетов, суммарный и средний баланс.
2. Список счетов с переводами.
3. Список счетов выбранного клиента.
4. Историю переводов выбранного счета.
5. Список клиентов, баланс которых превышает заданный порог.

## Текущее состояние
